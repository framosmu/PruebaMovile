PruebaMovile crea una pequeña base de datos SQLite en tu dispositivo movil Android, para observar así la capacidad de Omnis Studio para crear apps móviles, 
el menú de configuración permite conmutar entre el modo de trabajo Off-line y On-line, el modo On-line permite conectar con un servidor de aplicaciones
Omnis para actualizar la propia app o bien sincronizar datos con una base de datos central.

El repositorio incluye un AndroidWrapper modificado complétamente localizado al castellano y al ingles, una opción añadida para activar o no biometría 
haciendo más seguro el posible uso no autorizado de la app y la capacidad para activar o no el modo On-line cuando se detecta que el dispositivo tiene 
o no tiene conexión de red.

Además de esto podrá encontrar en el repositorio una guía, que explica cómo crear un nuevo proyecto Omnis, usando cómo base el AndroidWrapper modificado e 
incluido en éste repositorio.

La app también permite la recepción de notificaciones desde el servicio Firebase visuales o no visuales (sólo datos) para observar su uso.
El AndroidWrapper original sólo permitía el envío de notificaciones visuales, el que se encuentra en éste repositorio se ha modificado para poder enviar
también notificaciones silenciosas es decir sólo datos.
